❓ Частые вопросы
Откуда берутся данные о ценах?

Живые цены берутся из CoinGecko через наш собственный кэширующий прокси. Если API временно недоступен, калькулятор переключается на приблизительный исторический набор данных по нескольким крупным монетам — на чеке это всегда чётко помечено как «ОФЛАЙН ДЕМО-ДАННЫЕ», чтобы ты точно знал, что видишь.

Это финансовый совет?

Нет. CryptoFumble сделан для развлечения и размышлений, а не как инвестиционный совет. Он показывает гипотетический результат на основе исторических цен — это не прогноз и не рекомендация. Крипта волатильна, можно потерять деньги. Перед тем как инвестировать, всегда изучай вопрос самостоятельно.

Почему иногда пишет «офлайн демо-данные»?

Это значит, что живой API CoinGecko был временно недоступен (лимиты запросов, сбой сети), поэтому чек использовал приблизительный резервный набор данных вместо точных исторических цен. Он покрывает только BTC, ETH, SOL, DOGE, ADA, XRP и BNB — для любой другой монеты, если живые данные недоступны, ты увидишь ошибку, а не неверную цифру.
