❓ Perguntas frequentes
De onde vêm os dados de preços?

Os preços em tempo real vêm da CoinGecko, através do nosso próprio proxy com cache. Se a API ao vivo ficar indisponível por um momento, a calculadora usa um conjunto de dados históricos aproximados para algumas moedas principais — sempre marcado claramente como "DADOS DE DEMONSTRAÇÃO OFFLINE" bem no recibo, para você sempre saber o que está vendo.

Isso é uma recomendação financeira?

Não. O CryptoFumble existe para diversão e reflexão, não como conselho de investimento. Ele mostra um resultado hipotético baseado em preços históricos — não é uma previsão nem uma recomendação. Cripto é volátil e você pode perder dinheiro. Sempre pesquise por conta própria antes de investir.

Por que às vezes aparece "dados de demonstração offline"?

Isso significa que a API ao vivo da CoinGecko ficou temporariamente indisponível (limites de requisições, uma falha de rede), então o recibo usou um conjunto de dados de backup aproximado em vez de preços históricos exatos. Ele cobre apenas BTC, ETH, SOL, DOGE, ADA, XRP e BNB — para qualquer outra moeda, se os dados ao vivo falharem você verá um erro em vez de um número errado.
