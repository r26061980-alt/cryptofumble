❓ FAQ
Where does the price data come from?

Live prices come from CoinGecko, through our own caching proxy. If the live API is briefly unavailable, the calculator falls back to an approximate historical dataset for a handful of major coins — clearly marked "OFFLINE DEMO DATA" right on the receipt, so you always know which one you're looking at.

Is this financial advice?

No. CryptoFumble is for fun and reflection, not investment advice. It shows a hypothetical outcome based on historical prices — not a prediction or a recommendation. Crypto is volatile and you can lose money. Always do your own research before investing.

Why does it sometimes say "offline demo data"?

That means the live CoinGecko API was temporarily unreachable (rate limits, a network hiccup), so the receipt used an approximate backup dataset instead of exact historical prices. It only covers BTC, ETH, SOL, DOGE, ADA, XRP and BNB — for any other coin, if live data fails you'll see an error instead of a wrong number.
